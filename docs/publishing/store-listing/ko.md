## Description

```text
Convert The Spire Reborn은 Windows용 올인원 미디어 앱입니다. 다운로더, 변환기, 플레이어, 토렌트 클라이언트를 하나의 창에서 쓸 수 있습니다.

다운로드
• YouTube를 비롯한 1,800개 이상의 사이트에서 동영상과 음악을 MP4, MP3, M4A 등으로, 원하는 화질로 저장하세요.
• 재생 목록 전체를 한 번에, 제목·앨범 아트·태그까지 채워서.
• 내장 브라우저가 페이지 속 미디어를 찾아 줍니다.

변환
• FFmpeg로 오디오와 동영상을 27가지 이상의 형식으로 PC에서 바로 변환합니다. 아무것도 업로드하지 않습니다.

재생과 전송
• 재생 목록을 지원하는 음악·동영상 플레이어.
• 네트워크의 TV와 스피커로 전송(DLNA/UPnP).
• 함께 보기: 친구와 같은 동영상을 동기화해서 시청.

토렌트
• 완전한 BitTorrent 클라이언트: magnet 링크와 .torrent 파일, 비율 제한이 있는 시딩, 나만의 토렌트 만들기와 공유.

개인정보 우선
• 계정 없음, 광고 없음, 분석 없음, 추적 없음. 모든 것이 PC에 남습니다.
• GitHub의 오픈 소스(GPL-3.0).

18개 언어를 지원합니다. 다운로드할 권리가 있는 콘텐츠만 다운로드하세요.
```
