## Description

```text
Convert The Spire Reborn — універсальний медіазастосунок для Windows: завантажувач, конвертер, програвач і торрент-клієнт в одному вікні.

ЗАВАНТАЖЕННЯ
• Зберігайте відео й музику з YouTube та понад 1800 інших сайтів у MP4, MP3, M4A та інших форматах, у потрібній якості.
• Цілі плейлисти одразу, з назвами, обкладинками й тегами.
• Вбудований браузер сам знаходить медіа на сторінці.

КОНВЕРТАЦІЯ
• Конвертуйте аудіо й відео між понад 27 форматами за допомогою FFmpeg просто на комп'ютері. Нічого не вивантажується.

ВІДТВОРЕННЯ Й ТРАНСЛЯЦІЯ
• Програвач для музики й відео з плейлистами.
• Трансляція на телевізори й колонки у вашій мережі (DLNA/UPnP).
• Дивимося разом: те саме відео синхронно з друзями.

ТОРРЕНТИ
• Повноцінний BitTorrent-клієнт: magnet-посилання та .torrent-файли, роздача з обмеженням рейтингу, створення та поширення власних торрентів.

ПРИВАТНІСТЬ НАСАМПЕРЕД
• Без облікового запису, без реклами, без аналітики, без стеження. Усе залишається на вашому комп'ютері.
• Відкритий код (GPL-3.0) на GitHub.

Доступно 18 мовами. Завантажуйте лише той вміст, який маєте право завантажувати.
```
