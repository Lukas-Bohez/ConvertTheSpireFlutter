## Description

```text
Convert The Spire Reborn 把你的音乐和视频放进一个应用：带字幕、片段循环和大屏观看的播放器，以及填满它的各种方式，从下载、种子到能拦截广告的浏览器。

播放
• 歌曲和视频放在同一个媒体库，支持播放列表、收藏、随机和循环播放。
• 视频和歌曲都有字幕：文件旁边的 .srt 或 .vtt 会自动加载。一键开关，可以换一个字幕文件，不同步时还能调整时间。
• 循环最喜欢的片段：标记歌曲或视频中的一个或多个片段，只播放这些片段，一个接一个。
• 大屏观看：视频铺满屏幕，周围什么都没有。
• 0.5× 到 2× 的播放速度，以及在 15 到 60 分钟后或歌曲结束时停止的睡眠定时。
• 长视频和播客会从上次停下的地方继续播放。

下载
• 从 YouTube 和其他 1800 多个网站保存视频和音乐，格式有 MP4、MP3、M4A 等，画质任选，也可以只保存你想要的片段。
• 一次下载整个播放列表，标题、封面和标签都会填好。还能看到哪些歌曲还没有。
• 无需登录：应用从不索取你的 Google 或 YouTube 账号。

转换
• 用 FFmpeg 在你的电脑上转换音频、视频和图片，支持 27 种以上格式。不会上传任何内容。

投屏和一起看
• 投屏到你网络中的电视和音箱（DLNA/UPnP）。
• 一起看：和同一 Wi-Fi 下的朋友同步观看同一个视频。分享一个六位代码即可，无需账号，无需服务器。

种子
• 完整的 BitTorrent 客户端：磁力链接和 .torrent 文件、带分享率限制的做种，以及制作自己的种子。

浏览器
• 内置浏览器，使用 uBlock Origin 的过滤列表拦截广告和跟踪器，还能帮你找到页面上的媒体。

隐私至上
• 无需账号，无广告，无分析，无跟踪。一切都留在你的电脑上。
• 在 GitHub 上开源（GPL-3.0）。

支持 18 种语言。请只下载你有权下载的内容。
```
