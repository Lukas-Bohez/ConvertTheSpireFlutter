## Description

```text
Convert The Spire Reborn 是一款适用于 Windows 的一体化媒体应用：下载器、转换器、播放器和 BT 客户端，尽在一个窗口。

下载
• 从 YouTube 及 1800 多个其他网站保存视频和音乐，支持 MP4、MP3、M4A 等格式，画质任你选。
• 一次下载整个播放列表，自动填好标题、封面和标签。
• 内置浏览器帮你找到页面上的媒体。

转换
• 使用 FFmpeg 在 27 种以上格式之间转换音频和视频，全部在你的电脑上完成，不上传任何内容。

播放与投屏
• 支持播放列表的音乐和视频播放器。
• 投屏到家庭网络中的电视和音箱（DLNA/UPnP）。
• 一起看：与朋友同步观看同一个视频。

BT 下载
• 完整的 BitTorrent 客户端：磁力链接和 .torrent 文件、可设分享率上限的做种，以及创建和分享你自己的种子。

隐私优先
• 无需账户、无广告、无统计、无追踪。一切都留在你的电脑上。
• 在 GitHub 上开源（GPL-3.0）。

支持 18 种语言。请只下载你有权下载的内容。
```
