## Description

```text
Convert The Spire Reborn は Windows 向けのオールインワン メディア アプリです。ダウンローダー、コンバーター、プレーヤー、トレント クライアントがひとつのウィンドウに。

ダウンロード
• YouTube をはじめ 1,800 以上のサイトから動画や音楽を、MP4、MP3、M4A などの形式で、好きな画質で保存。
• プレイリストをまるごと一括で。タイトル、アートワーク、タグも自動で付きます。
• 内蔵ブラウザーがページ上のメディアを見つけます。

変換
• FFmpeg で音声と動画を 27 以上の形式に変換。すべて PC 上で処理し、何もアップロードしません。

再生とキャスト
• プレイリスト付きの音楽・動画プレーヤー。
• ネットワーク上のテレビやスピーカーにキャスト（DLNA/UPnP）。
• 一緒に見る：同じ動画を友だちと同期して視聴。

トレント
• 本格的な BitTorrent クライアント：magnet リンクと .torrent ファイル、比率制限付きのシード、自分のトレントの作成と共有。

プライバシー第一
• アカウント不要、広告なし、分析なし、追跡なし。すべてが PC の中に残ります。
• GitHub でオープンソース（GPL-3.0）。

18 言語に対応。ダウンロードする権利のあるコンテンツだけをダウンロードしてください。
```

## What's new in this version

```text
ファイルの完了時やシード開始時に、トレントがアプリをフリーズさせなくなりました。曲をもう一度再生しても音量が変わりません。別のページを開いても全画面表示 (F11) が維持されます。変換のすべての形式が使えるようになりました（PDF からのテキストや WebP 画像を含む）。新機能: プレイリストから曲を曲リスト (.txt または .csv) としてエクスポートし、別のデバイスでインポートできます。
```
