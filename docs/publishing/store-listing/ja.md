## Description

```text
Convert The Spire Reborn は、音楽と動画をひとつのアプリにまとめます。字幕、パートのループ、大きく表示に対応したプレーヤーと、それを満たすあらゆる手段。ダウンロードやトレントから、広告をブロックするブラウザまで。

再生
• 曲と動画をひとつのライブラリに。プレイリスト、お気に入り、シャッフル、リピート。
• 動画にも曲にも字幕。ファイルの隣にある .srt や .vtt は自動で読み込まれます。ワンタップでオン・オフ、別のファイルを選ぶことも、ずれていればタイミングを調整することもできます。
• 歌詞の同期表示：曲の隣にある .lrc ファイルで、歌われている行を表示します。
• いちばん好きなパートをループ。曲や動画のパートをひとつ以上マークすると、そこだけを順番に再生します。
• 大きく表示：動画が画面いっぱいに。まわりには何もありません。
• 0.5×〜2× の再生速度と、15〜60 分後または曲の終わりで止まるスリープタイマー。
• 長い動画やポッドキャストは、前回の続きから再生。

ダウンロード
• YouTube をはじめ 1,800 以上のサイトから、動画と音楽を MP4、MP3、M4A などで保存。画質も選べて、必要なパートだけを保存することもできます。
• プレイリストをまるごと一度に。タイトル、カバー、タグも入ります。まだ持っていない曲もわかります。
• ログイン不要：Google や YouTube のアカウントを求めることはありません。

変換
• FFmpeg で音声、動画、画像を 27 以上の形式に、PC 上で変換。何もアップロードされません。

キャストと一緒に見る
• ネットワーク上のテレビやスピーカーにキャスト（DLNA/UPnP）。
• 一緒に見る：同じ動画を、同じ Wi-Fi の友だちと同時に。6 文字のコードを共有するだけ。アカウントもサーバーも不要です。

トレント
• 本格的な BitTorrent クライアント：マグネットリンクと .torrent ファイル、比率制限つきのシード、自分のトレントの作成。

ブラウザ
• uBlock Origin と同じフィルターリストで広告とトラッカーをブロックし、ページ上のメディアを見つけてくれる内蔵ブラウザ。

プライバシー重視
• アカウントなし、広告なし、分析なし、トラッキングなし。すべて PC の中にとどまります。
• GitHub でオープンソース（GPL-3.0）。

18 言語に対応。ダウンロードする権利のあるコンテンツだけをダウンロードしてください。
```

## What's new in this version

```text
新機能：動画や曲の必要なパートだけをダウンロード。動画と曲の字幕：.srt と .vtt は自動で読み込まれます。.lrc ファイルによる歌詞の同期表示。MKV や MP4 に埋め込まれた字幕も表示されます。いちばん好きなパートをループ、速度を変更、スリープタイマーを設定、大きく表示で視聴。長い動画は前回の続きから再生し、ブラウザの広告ブロックは uBlock Origin のリストを使うようになりました。プレーヤーの操作ボタンはひとつにまとまり、動画の表示領域が広がりました。すべての色が解放されています。修正：トレントでダウンロードしたプログラムがシード中でも起動でき、すでに持っているファイルのトレントはすぐにシードされ、ライブラリの動画にサムネイルが付きました。
```
