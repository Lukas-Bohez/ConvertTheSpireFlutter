## Install

**On Windows, the easiest way is the [Microsoft Store](https://apps.microsoft.com/detail/9mt834rpf8zp?cid=DevShareMCLPCS).** Press **Get** and it installs. Microsoft signs it, so Windows shows no warning, and the Store keeps it up to date. It is the same app, with every feature of the downloads below.

| | Download | Then |
|---|---|---|
| **Windows: Microsoft Store** | [Get it from Microsoft](https://apps.microsoft.com/detail/9mt834rpf8zp?cid=DevShareMCLPCS) | Press **Get**. No "Windows protected your PC" warning, and the Store updates it for you. |
| **Windows: installer** | `ConvertTheSpireReborn-Setup.exe` | Double-click it. It installs for your account, adds a Start menu entry, and the app updates itself from then on. |
| **Android phone or TV** | `ConvertTheSpireReborn.apk` | Open it and allow the install. |
| **macOS** | `ConvertTheSpireReborn-macOS.dmg` | Open it and drag the app into Applications. |
| **Google Play** | [The Play Store version](https://play.google.com/store/apps/details?id=com.torrentspire.ai) | Everything except YouTube downloads, which Play does not allow. |

No-install options are here too: the Windows zip (extract and run `convert_the_spire_reborn.exe`) and the Mac zip.

All downloads side by side, with a tour of what the app does: **[quizthespire.com/tools/convert](https://quizthespire.com/tools/convert)**.
